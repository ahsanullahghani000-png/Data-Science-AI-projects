## Getting Started

You can explore and run these notebooks on your local machine.

### 1. Clone the Repository

```bash
git clone https://github.com/ahsanullahghani000-png/Data-Science-AI-projects.git
```

### 2. Navigate to the Repository

```bash
cd Data-Science-AI-projects
```

### 3. Create a Virtual Environment (Recommended)

```bash
python -m venv venv
```

Activate it on Windows:

```bash
venv\Scripts\activate
```

### 4. Install Basic Dependencies

```bash
pip install numpy pandas matplotlib seaborn scikit-learn jupyter
```

Some notebooks may require additional libraries such as TensorFlow, Keras, Plotly, or yfinance. Install those according to the notebook you want to run.

### 5. Launch Jupyter Notebook

```bash
jupyter notebook
```

Open any `.ipynb` file and run the cells.
