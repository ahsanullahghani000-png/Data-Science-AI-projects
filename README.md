## 📖 About

This repository is my personal learning portfolio. Each notebook is a hands-on project where I practice the full data science workflow: **data cleaning → exploration → visualization → model building → evaluation**. New projects are added as I learn more.

## 📂 Projects

| # | Project | Description | Type |
|---|---------|-------------|------|
| 1 | [Student Record](./project_1%20student%20Record.ipynb) | Analysis and handling of student records data | Data Analysis |
| 2 | [Super Store](./project_2%20Super%20Store%20.ipynb) | Sales and profit analysis of a retail store | EDA & Visualization |
| 3 | [Taxi Trip Duration](./Project%203%20taxi%20trip%20duration.ipynb) | Predicting how long a taxi trip will take | Regression |
| 4 | [House Prices](./Project%204%20House%20Prices%20.ipynb) | Predicting house prices from property features | Regression |
| 5 | [Heart Disease](./05%20project%20heart%20desease.ipynb) | Predicting heart disease from patient health data | Classification |
| 6 | [End-to-End Heart Disease](./pjoject%206%20END%20TO%20END%20HEART%20DESEASE.ipynb) | Complete ML pipeline from raw data to final model | End-to-End ML |
| 7 | [HR Employee Attrition](./HR%20Employee%20Attrition%20.ipynb) | Finding why employees leave and predicting attrition | Classification |

## 🛠 Tech Stack

- **Language:** Python
- **Data:** Pandas, NumPy
- **Visualization:** Matplotlib, Seaborn
- **Machine Learning:** Scikit-learn
- **Environment:** Jupyter Notebook

## ⚙️ How to Run

1. Clone the repository
```bash
   git clone https://github.com/ahsanullahghani000-png/Data-Science-AI-projects.git
```
2. Go into the folder
```bash
   cd Data-Science-AI-projects
```
3. Install the libraries
```bash
   pip install pandas numpy matplotlib seaborn scikit-learn jupyter
```
4. Open Jupyter and run any notebook
```bash
   jupyter notebook
```
